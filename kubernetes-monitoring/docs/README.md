## 1. Введение

### Prometheus Operator
Способ установки Prometheus в кластер Kubernetes в виде operator и набора CRD. Позволяет конфигурировать сбор метрик с объектов кластера, создавая и настраивая custom-объекты k8s.

В задании вы установите Prometheus Operator удобным вам способом.

### Exporter
Приложения, обеспечивающие сбор метрик с какого-либо объекта и отдачу их в Prometheus-формате. Существуют различные экспортеры под популярные программные продукты (например, nginx, Kafka, HAProxy и т. д.), а также для различных языков и фреймворков для разработки приложений. Если по каким-либо причинам ни один экспортер вам не подходит, можно написать свой.

В задании мы будем использовать exporter для nginx, который будет собирать метрики с веб-сервера и преобразовывать их в Prometheus-формат.

## 4. Пошаговая инструкция выполнения домашнего задания

- Необходимо создать кастомный образ nginx, отдающий свои метрики на определенном endpoint (пример из официальной документации в разделе ссылок).
- Установить в кластер Prometheus Operator любым удобным вам способом (рекомендуется ставить либо по ссылке из официальной документации, либо через Helm chart).
- Создать deployment, запускающий ваш кастомный nginx-образ, и service для него.
- Настроить запуск nginx Prometheus exporter (отдельным pod'ом или в составе pod'а с nginx — не принципиально) и сконфигурировать его для сбора метрик с nginx.
- Создать манифест ServiceMonitor, описывающий сбор метрик с pod'ов, которые вы создали.
