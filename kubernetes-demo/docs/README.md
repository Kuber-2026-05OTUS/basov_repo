# O. kubernetes-demo
Методическое пособие по выполнению проектной работы курса

Инфраструктурная платформа на основе Kubernetes

Цель: разворачивание и описание разработки проекта с airflow в k8s со скачиванием курса доллара к рублю у ЦБ и запись результатов в MongoDB через PySpark.

## 1. Введение

Устанавливается Airflow в Kubernetes в рамках Яндекс Облака, разворачивание stable версии и мониторинг метрик, совместно с системой логирования и мониторинга.

## 2. Цели домашнего задания

- Журналирование возможных ошибок.
- Развернуть стабильную версию Airflow в Kubernetes на Яндекс Облаке.
- Обеспечить регулярное скачивание курса доллара к рублю с сайта ЦБ.
- Выполнить обработку данных PySpark и сохранить результат в MongoDB.
- Подготовить мониторинг, который будет собирать метрики с веб-сервера Airflow и преобразовывать их в Prometheus-формат.

## 3. Описание домашнего задания

### Подготовка
- Создать ветку kubernetes-demo и папку kubernetes-demo.
- Включить в checklist/README.md проверки готовности решения.

### Развертывание
- Развернуть Airflow в k8s на Яндекс Облаке.
- Настроить DAG для регулярного скачивания курсов доллара к рублю с сайта ЦБ.
- Настроить PySpark задачу в DAG для обработки данных и сохранения в MongoDB.

### Мониторинг и логирование
- Подключить мониторинг и журналирование.

### Сдача
- Добавить файлы в ветку kubernetes-demo в каталог kubernetes-demo.
- В README.md написать сценарий для записи демо видео.
- В docs/cloud/README.md сделать детальную инструкцию администратору облака

## 4. Пошаговая инструкция выполнения домашнего задания

- Развернуть managed Kubernetes в Яндекс Облаке, создать кластер и узлы.
- Установить Airflow в кластере, обеспечить HA-режим и интеграцию с внешним хранилищем/секретами.
- Настроить DAG для периодического скачивания курса USD/RUB с ЦБ и сохранения результатов в MongoDB через PySpark.
- Настроить Secrets и безопасное хранение конфиденциальных данных.
- Добавить манифесты, инструкции и переменные в README и репозитории.
